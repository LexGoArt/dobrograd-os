# Операційна система будівельного блоку

Внутрішній портал технічного блоку Iron Invest / Доброград: регламенти, форми, строки, ролі і процеси служби замовника - трьома мовами (uk / ru / en).

## Стек

- [Astro 5](https://astro.build) - статична збірка, нуль зайвого JS
- Tailwind CSS 4 - дизайн-токени системи
- [Pagefind](https://pagefind.app) - клієнтський пошук трьома мовами
- Дані: `src/data/<lang>/*.json`, генеруються конвеєром з Excel-файлів системи

## Команди

```bash
npm install          # залежності
npm run data         # перегенерувати дані з дампів (scripts/build_data.py)
npm run build        # збірка + індекс пошуку -> dist/
npm run preview      # локальний перегляд збірки
```

## Структура

- `scripts/build_data.py` - конвеєр: дампи Excel -> src/data/uk (тут же зашиті виправлення аудиту контенту)
- `scripts/merge_translations.py` - збирання перекладів ru/en
- `src/pages/[lang]/…` - сторінки трьома мовами з одного коду
- `content/` - машиночитаємі дампи вихідних Excel-файлів
- `drive-links.json` - карта «індекс документа -> файл на Google Диску»

Джерело істини за формами - файли на Google Диску компанії. Сайт - дзеркало-інструкція.
